# GLM-5 AI 智能助手 - 介绍

一个介绍 GLM-5 AI 智能助手的单页静态网站，纯 HTML 实现，无需构建即可本地打开或部署到 GitHub Pages。

## 功能列表

- 页面标题与主视觉：GLM-5 AI 智能助手介绍
- 内容目录：快速跳转到各章节
- 关于我：助手定位与简介
- 核心能力：主要能力点展示
- 技术架构：技术组成说明
- 使用场景：典型应用场景列举
- 我的优势：差异化亮点
- 准备好了吗？：结尾引导区块
- 附带 `.nojekyll` 文件，确保 GitHub Pages 正常发布静态资源

## 如何本地打开

1. 下载或克隆本仓库到本地。
2. 直接双击 `index.html`，用浏览器打开即可。
3. 也可以在当前目录启动一个本地静态服务器，例如：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000/index.html`。

## 部署到 GitHub Pages

将仓库推送到 GitHub 后，在仓库 Settings → Pages 中选择分支与根目录发布，入口文件为 `index.html`。
